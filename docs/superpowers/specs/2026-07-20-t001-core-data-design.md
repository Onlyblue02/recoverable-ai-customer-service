# T-001 核心业务数据与场景基线设计

## 1. 目标与范围

T-001 建立后续功能和验收共用的、带版本的合成业务事实集。数据覆盖用户、商品、订单、已有模拟售后申请和政策，并以自动化测试保证引用关系、金额、日期、政策范围及关键场景一致。

本任务不实现数据库模型、迁移或 seed 执行器，不实现订单 API、政策检索、资格规则、Agent、工作流和审批，也不定义 T-002 的自然语言输入、过程断言或预期终态。

## 2. 固定业务口径

- 数据集版本为 `1.0.0`。
- 固定业务基准日为 `2026-07-20`，测试不得读取系统当前日期。
- 普通无理由退货数据口径为签收后 7 个自然日；相差 7 天的记录用于边界日期场景，相差 8 天的记录用于超期场景。
- 质量问题政策数据口径为签收后 30 个自然日。
- 高金额样本订单金额为 CNY 9,999；本任务不定义高金额规则阈值或资格结论。
- 第一版本每个订单只有一个目标商品行，以匹配一个退货工作流只处理一个订单商品的架构约束。
- 全部身份均使用演示名称、稳定合成标识和 `example.invalid` 保留域名，不保存电话、地址、证件号或真实个人信息。

这些口径只描述数据事实及其设计用途，不构成 T-103 资格规则实现。

## 3. 数据组织

采用版本化 JSON 文件，不新增解析依赖：

```text
data/
├── README.md
├── manifest.json
├── seed/
│   ├── users/users.v1.json
│   ├── products/products.v1.json
│   ├── orders/orders.v1.json
│   └── service_cases/service_cases.v1.json
└── knowledge/
    ├── active/policies.v1.json
    ├── expired/policies.v1.json
    └── conflicting/policies.v1.json
```

`manifest.json` 保存数据集版本、固定基准日、文件清单和覆盖标签。每条关键记录保存 `scenario_tags`、`business_purpose` 和 `expected_behavior`，使业务用途可审阅，但不包含对话措辞或端到端断言。

## 4. 场景表达

订单数据至少包含：

- 正常退货：当前用户拥有、已签收、处于普通窗口内的低金额订单。
- 质量问题：当前用户拥有、已签收且商品存在合成质量问题描述的订单。
- 边界日期：签收日至基准日恰好 7 天。
- 超期退货：签收日至基准日恰好 8 天。
- 高金额订单：金额为 CNY 9,999 的已签收订单。
- 越权订单：真实存在但归属于另一演示用户，并由清单记录测试主体用户。
- 不存在订单：清单保存一个未出现在订单集合中的保留 ID。
- 已有模拟售后申请：独立订单关联一个合成申请，用于证明售后申请数据实体有一致样本；不实现幂等或创建行为。

政策数据至少包含：

- 当前有效普通退货政策。
- 当前有效质量问题政策。
- 已过有效期且在基准日不可用的政策。
- 两份同时有效、适用范围重叠且结论矛盾的政策。
- 一个存在于商品目录但没有任何政策覆盖的类别，用于稳定表达无结果场景。

## 5. 一致性约束

自动化测试验证：

- 所有文件声明相同数据集版本，且清单引用文件全部存在。
- 用户、商品、订单、商品行和售后申请标识唯一。
- 每个订单用户、商品行商品和售后申请订单均可解析到真实记录。
- 订单商品行小计之和等于订单总额，货币一致，数量和金额为正数。
- 下单时间不晚于签收时间，签收时间不晚于固定基准日。
- 场景日期差分别满足窗口内、7 天边界和 8 天超期的设计口径。
- 越权订单属于另一演示用户；不存在订单 ID 确实不存在。
- 当前政策在基准日有效，过期政策在基准日前失效。
- 冲突政策在基准日同时有效、适用同一类别且结论相反。
- 无结果商品类别不被任何政策覆盖。
- 数据包含全部要求的场景标签，并且不包含电话、地址、证件号或非保留域名邮箱。

测试只读取 JSON 并验证事实，不调用数据库、网络或应用业务接口。

## 6. 错误处理与可维护性

JSON 解析错误、缺失文件、重复标识、悬空引用、金额不平、日期矛盾和覆盖缺失均直接导致 pytest 失败。日期使用 ISO 8601 UTC 时间或 ISO 日期，金额使用字符串形式的十进制定点值，避免浮点误差。

新增数据版本时应新增版本化文件并更新清单，不原地改变已被验收引用的旧版本语义。后续数据库 seed、政策导入和固定验收用例应消费这些事实文件，而不是复制一份不同口径的数据。
