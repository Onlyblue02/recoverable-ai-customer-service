# T-302 中断恢复与重复执行保护

T-302 的公开检查点请求仅允许 `workflow_id` 和 `approval_id`。服务端从审批仓储重新读取审批、用户、订单/商品行、政策引用、资格、版本和决定；调用方不能提交或覆盖这些事实。检查点由服务端写入固定的 `workflow_version=1.0.0` 和 schema version，并维护 CAS revision；恢复前必须精确匹配当前支持版本。导出后导入新仓储可恢复同一等待审批任务；版本缺失、不兼容或 CAS 冲突均安全失败。

恢复不重新收集信息或创建新审批。可信 `approved` 审批从已保存中断点调用受控模拟申请端口，并使用既有稳定键先查后写；重复恢复复用同一申请。写后异常或未确认状态会标为未知，后续恢复不盲目重试或声称完成。`pending`、调整和拒绝保持各自安全状态；越权、绑定不一致、未知操作或仓储异常均为 `FAILED_SAFE`。最终回复质量门禁仍属 T-303。
