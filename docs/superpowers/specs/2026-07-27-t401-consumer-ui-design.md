# T-401 消费者对话界面设计

T-401 提供最小消费者会话：消息历史、处理状态、下一步提示、政策引用、授权订单白名单和模拟申请编号。

前端默认使用 `HttpConversationClient` 调用最小 HTTP 会话入口。浏览器只提交消息，并在本地保存会话 ID；服务端保存进程内会话快照和可信收集上下文，刷新后可通过 `GET /api/v1/conversations/{id}` 恢复当前状态和历史。未知或重启后失效的会话不会声称完成：加载时安全创建新会话，发送失败则呈现脱敏错误与重试/人工提示。

服务端依据既有确定性 T-201 路由分派：政策咨询调用 T-101 并仅返回实际引用；订单查询调用受可信用户上下文约束的 T-102 并仅返回白名单；标准退货调用 T-203。UI 不调用真实模型，DeepSeek/Fake 不在此 HTTP 链路中；权限、资格、审批和申请写入仍由既有确定性服务决定。

本任务不实现 SSE、生产数据库或持久化历史、T-402 审批界面、真实退款或高风险审批决定。
