# T-402 人工审批界面设计

T-402 新增审批列表、详情和决定界面。浏览器只发送决定、备注、调整建议和乐观版本；可信审批人身份、订单、资格、政策引用和风险事实均由服务端既有 T-301/T-304 数据读取。

消费者高风险退货由服务端创建并绑定同一 T-304 工作流、检查点与审批任务；审批决定通过既有恢复入口执行并回写消费者会话。批准可产生唯一模拟申请，调整和拒绝不创建申请。

界面显示待处理、已处理和安全失败状态，并以白名单展示授权订单摘要、完整政策引用、资格结论、规则和升级原因。默认 HTTP 客户端在组件生命周期内保持稳定；提交期间同步锁定，冲突或网络失败后重新读取可信服务端状态。终态任务不可重复提交。本任务不增加 SSE、数据库持久化、真实退款或新的审批规则。
