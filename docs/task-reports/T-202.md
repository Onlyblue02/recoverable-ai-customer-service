## Reviewer 修复

- 根因：原因识别优先命中被否定的旧短语，不能表达“不是旧值，是新值”；可信订单号的纯空白值规范化为 `""` 而未被识别为缺失。
- 修复：增加受限、可审计的双向原因更正结构，优先采用新值；纯空白订单号统一规范化为 `None`，稳定进入订单号收集。
- 回归：新增 quality→changed_mind 与 changed_mind→quality 双向更正、修正结果作为下一轮可信上下文、同一更正确定性、空字符串/空白订单号以及合法带空格小写订单号的公开路径测试。修复后专项 14 passed、全仓 Python 测试 195 passed；本轮仍等待 Reviewer 复审，未标记 PASS。

## Reviewer 第二轮修复

- 根因：上一轮更正规则只列出部分已支持原因词，且商品状态没有否定更正模式；被否定旧值可能先于新值被普通模式匹配。
- 修复：原因与商品状态均以“不是旧值，是新值”的受限结构优先解析，词表覆盖当前声明支持的原因与状态表达；通用槽位修订逻辑继续记录唯一连续变更。
- 回归：新增 `不需要`、`故障` 的原因更正，以及已使用/未使用、破损/完好的商品状态双向更正，逐项验证最新值、修订值和序号，并将结果作为下一轮可信上下文。修复后专项 20 passed、全仓 Python 测试 201 passed。
