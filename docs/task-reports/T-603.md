# T-603 DeepSeek 意图识别与结构化计划协议

## 范围

本任务使 DeepSeek 或确定性 Fake 仅产生并校验 `agent-plan-v1` 候选计划。它不注册工具、不调用工具、不执行订单写入、不裁决退货资格，也不创建或决定审批。

## 实现

- 新增 `ModelTask.AGENT_PLAN_GENERATION` 和冻结的 `AgentPlanCandidate`。协议固定包含版本、意图、能力候选、受限提取字段、澄清字段与不确定性原因，拒绝额外字段。
- DeepSeek 延用既有 JSON 模式与一次修复上限。非法 JSON、缺字段、未知意图或非法能力在修复后仍不合格时返回 `INVALID_OUTPUT`；不会产生可执行计划。
- Fake 计划输出完全确定；测试注入的非法结构返回安全的 `INVALID_OUTPUT`，不抛出未处理异常。
- `AgentPlanService` 对意图与能力组合做确定性策略校验。仅 `policy.lookup`、`order.get_authorized`、`return.evaluate`、`clarify`、`escalate` 可出现；其中前三者只是候选标识，未发生调用。
- 合法可继续计划仅从 T-602 的 `PLANNING` 进入 `VALIDATING_PLAN`；不确定性只路由到 `CLARIFYING` 或 `ESCALATING`。模型/结构/策略失败进入 `FAILED_SAFE` 并记录稳定原因码。
- 审计元数据仅保留计划版本、意图、能力、模型状态和原因码；不保存提示词、原始模型内容或推理链。
