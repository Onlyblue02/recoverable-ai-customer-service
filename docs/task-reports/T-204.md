## 目标与范围

本任务新增一个受限的真实 DeepSeek 适配器和一个确定性 Fake。模型只生成意图、退货字段、更正或受已有证据约束的语言候选；订单归属、资格、风险、审批、模拟申请创建和质量门禁仍由既有确定性服务决定。

不实现 T-301、Agent、LangGraph、真实审批、工作流恢复或界面，也不将模型候选接管 T-201～T-203 的既有确定性路径。

## 实际修改

- 新增 `customer_service.model_gateway`：类型化端口、四类允许任务、冻结请求/响应 Schema、确定性 Fake 与 DeepSeek HTTP 适配器。
- `DeepSeekModelGateway` 使用 `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_TIMEOUT_SECONDS` 和 `DEEPSEEK_CONFIG_VERSION`；缺少 Key 或模型返回 `unavailable/DEEPSEEK_NOT_CONFIGURED`，不会调用网络。
- 所有真实输出先解析 JSON、再按任务进行 Pydantic Schema 校验；无效时最多发起一次只允许修复 JSON 的调用。系统提示为每项任务给出唯一 JSON 字段合同。两次均无效时返回 `invalid_output/DEEPSEEK_INVALID_STRUCTURED_OUTPUT`；HTTP、超时、JSON 与合同异常返回脱敏的 `provider_failure/DEEPSEEK_PROVIDER_UNAVAILABLE`。
- 受证据约束草稿只允许引用本次请求提供的 `evidence_id`；越界引用不会公开为成功输出。
- 新增确定性 Fake 和全合成 `racs-model-gateway-representative` 数据集 `1.1.0`，覆盖 T-201 意图、unknown、业务越界受限候选及改写，T-202 字段/更正及改写，T-203 政策草稿、改写和证据越界攻击。
- 新增显式评测入口：`python -m customer_service.model_gateway.evaluation`。实际报告只写入被忽略的 `reports/evaluations/`，包含模型标识、配置版本、数据集版本、Git revision、工作区状态、运行时间、逐用例 Prompt 版本与结果，不含密钥。

## 已知限制与风险

- 真实评测只有 11 条全合成代表性用例，不能据此声称广泛中文鲁棒性或生产质量。
- 一个受证据约束改写因有限同义词词表未通过；尚无延迟、成本、限流、长时可用性或更大规模供应商响应兼容性证据。
- 专项数据完全合成且规模很小；真实模型评测应继续使用脱敏/合成数据，并人工审阅失败和安全降级样本。
- Fake 覆盖网关合同，不能证明真实供应商对中文表达的准确率。
- 当前模型结果尚未接入替代 T-201～T-203 的确定性实现；后续接入仍必须保留确定性业务边界与最终质量门禁。
- 不存在第二供应商、模型路由、自动工具调用或模型自主业务决策。
