## 目标与范围

使用 T-001 固定政策数据实现当前有效政策的确定性筛选、引用回答和证据不足安全结果。本任务不实现自然语言抽取、HTTP API、数据库/向量索引、Agent、LangGraph、订单查询、资格规则、审批、界面或 T-102。

## 实际修改

- 新增不可变类型化政策文档、查询、引用和回答结果。
- 从 `data/manifest.json` 声明的 knowledge 文件加载 T-001 政策，验证数据集版本、文件存在、政策结构、有效期顺序和政策 ID 唯一性。
- 按类别、退货原因、`published` 状态和包含性有效期执行确定性过滤，默认使用 T-001 固定基准日 `2026-07-20`，不读取系统当天日期。
- 当前政策唯一明确时使用确定性模板回答，并返回本次实际使用政策的 ID、版本、标题、来源、有效期和内容摘录。
- 只有过期政策、无结果、缺少必要原因、多来源含糊或政策冲突时不生成确定性答案和引用；分别返回澄清或升级建议。
- 组件测试直接读取 T-002 政策相关固定用例的语义实体、期望公开内容和禁止内容，不以示例措辞完整相等作为判定条件。
- 根据定向复审补充政策专用证据绑定：`answer()` 保留本次实际检索并选中的当前政策，答案组装后逐字段核对政策 ID、稳定证据 ID、版本、来源、有效期和内容；无法绑定时清空答案与引用，并返回 `INSUFFICIENT_EVIDENCE / UNGROUNDED_CITATION`。
- 新增公开服务路径对抗测试，覆盖政策 ID、证据 ID、版本、来源同时或分别伪造，以及引用其他未被本次查询检索到的真实政策；正常真实引用继续返回 `ANSWERED`。

## 已知限制与风险

- 当前使用固定 JSON 和精确属性过滤，没有 PostgreSQL/pgvector、Embedding 或语义召回；不能把它描述为最终向量检索架构。
- 当前调用方必须提供结构化类别和可选退货原因；自然语言理解属于 T-201。
- 当前没有 HTTP API、会话、Agent、工作流或产品界面。
- 引用作为不可变组件结果返回，但尚未持久化为数据库证据快照。
- 当前证据 ID 由政策 ID 和政策版本稳定生成，绑定校验发生在单进程内；尚无持久化、签名或跨进程防篡改证据快照。
- 冲突结果只返回 `ESCALATE` 建议，不创建人工审批；审批属于 T-301。
- 当前测试证据来自本地命令，缺少 CI 链接。
- 本次环境没有 `docker` 命令，Compose 配置未重新验证；保留历史执行者通过记录。
- T-101 只校验政策回答内部证据；订单、资格、审批与执行状态的通用最终回复门禁仍属于 T-303，尚未实现。
