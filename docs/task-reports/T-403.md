- 新增 `customer_service.acceptance_reporting.runner`，使用既有公开消费者和审批 HTTP 路径执行政策、授权订单、订单防枚举、标准退货、审批恢复和 payload 身份伪造边界；新增检查点导出/导入恢复、无依据回答、虚假完成和审批绕过门禁运行路径。
