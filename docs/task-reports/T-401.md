## 实际修改

- 新增消费者单页，显示会话消息、处理状态、下一步提示、政策引用与已确认的模拟申请编号。
- 默认 `HttpConversationClient` 只发送用户消息至最小服务端会话入口；不再使用浏览器内的合成完成演示。
- 服务端为每个会话保存可信收集上下文，并注入固定合成消费者身份；它调用既有 T-203 标准退货公开编排，因此只有授权订单、可用政策、低风险资格及 `ServiceCaseService` 实际 `created` 或 `existing` 时才返回 `completed`。
- 公开消息请求拒绝身份、订单事实、资格或申请成功字段。前端仅显示白名单状态、提示、政策引用和已确认申请编号；没有 SSE、持久化历史、审批界面或高风险审批 UI。
- 修复后会话入口按既有确定性路由分派政策咨询、订单查询和标准退货；服务端提供最小 GET 快照恢复，浏览器只保存会话 ID。UI 不调用 DeepSeek 或 Fake，模型适配仍属于 T-204 独立边界。
